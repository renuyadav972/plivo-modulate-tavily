# Contributing

Built in a day for a workshop, so there is plenty to improve.

Especially useful:

- **A config flag that makes Velma stream `behavior_detection` events.** We
  could not find one. See the measurements in the README. If you get it working,
  this is the highest-value fix in the repo.
- Adapters for other stacks. LiveKit, Vapi, or a bare Twilio-style loop.
- Fresh latency numbers. Ours are from 5 October 2026 and will drift.

Measurements beat opinions. If you change a claim in the README, include the
script that produced the new number.
